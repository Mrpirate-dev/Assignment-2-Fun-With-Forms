# Assignment-2-Fun-With-Forms
**Module 2 - Assignment 2**

This is a group submission for Dynamic Websites and Applications by Anthony Hamilton and Nickolas Williams. It has three questions, and each one is in its own file.

Project files

question1.html parses the JSON with JSON.parse() and shows the employees as a bulleted list, built with a template literal. Question2.html and style.css make up the Fun With Forms page, which uses the jQuery Validate plugin to make every field required with custom messages. The card fields are greyed out when PayPal is selected, the shipping fields are hidden when "Same as Billing" is ticked, and an email field only accepts a valid email address. jquery.min.js and jquery.validate.min.js are the libraries the form needs. The files for Question 3 will be added once it is complete.

Running the project

Open question1.html or Question2.html in a web browser. Keep all of the files together in the same folder. The form is a demonstration only, so nothing is saved or sent anywhere.
